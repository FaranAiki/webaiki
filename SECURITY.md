# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to faran.aiki.business@gmail.com or in the website itself. All security vulnerabilities will be promptly addressed.

Please include:
- A description of the issue
- Steps to reproduce the issue
- Potential impact of the vulnerability

Please do not disclose the issue publicly until I have had a chance to address it.
