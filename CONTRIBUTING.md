# Contributing to webaiki

First off, thank you for considering contributing to webaiki!

## Code of Conduct
By participating in this project, you are expected to adhere professionalism and respect.

## How Can I Contribute?

### Reporting Bugs
- Use the **Bug Report** template.
- Provide a clear, step-by-step reproduction guide.

### Suggesting Enhancements
- Use the **Feature Request** template.
- Explain the "why" behind the feature, not just the "what".

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`npm test`).
4. Make sure your code lints (`npm run lint`).
5. Use **Conventional Commits**:
   - `feat:` for new features.
   - `fix:` for bug fixes.
   - `docs:` for documentation changes.
   - `style:` for formatting, missing semi-colons, etc.
   - `data:` for additional data
